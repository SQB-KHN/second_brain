# Statistical Analysis Engine (SecondSelf 3.1)

Open **Datasets**, register a local table, and choose **Analyse this version**, or select **Analyse** in the sidebar. Choose a registered immutable version, a procedure and ordered variables. Preview exclusions, then run and save. History is scoped to the version, paginated in groups of 20, and survives restarts. Download the entire manifest as JSON or spreadsheet-safe long-form CSV. No raw dataset is modified or exported by these actions.

Supported procedures:

| Procedure | Variable order | Outputs and checks |
| --- | --- | --- |
| Exploratory | 1–20 numeric variables | Mean, median, sample SD, range, quartiles, skewness, t-based mean CI, histograms, normality |
| Pearson / Spearman | Two numeric variables | Correlation effect size, two-sided p, CI, scatter, normality; review linearity/monotonicity |
| Paired t | First minus second, one matched pair per row | t, df, p, mean difference CI, Cohen dz, difference normality and histogram |
| Independent t | Numeric measurement, two-level group | Welch by default; optional pooled variance; t, df, p, difference CI, pooled-SD Cohen d, group means/counts, Levene, normality and histograms |
| Chi-square | Two categorical variables | Pearson chi-square without Yates correction, df, p, Cramer V, observed/expected counts, sparse-cell warning, count chart |
| OLS | Numeric outcome, then 1–10 numeric predictors | Intercept, slopes, conventional SE, t, p, coefficient CIs, R²/adjusted R², F, AIC/BIC, RMSE, VIF, condition number, residual Shapiro, Breusch–Pagan, Durbin–Watson, maximum Cook distance, residual and Q-Q plots |
| Binary logistic | Numeric 0/1 outcome (event 1), then 1–10 numeric predictors | Coefficients, conventional SE, z, p, CIs, odds ratios and CIs, likelihood/null likelihood, LR p, McFadden pseudo-R², AIC/BIC, convergence, Brier score, accuracy at .5, probability/observed chart |

All intervals use the selected 90%, 95% or 99% confidence level. Pearson uses SciPy's Fisher-transform CI. Spearman uses an explicitly labelled approximate Fisher transform of ranks; its CI is unavailable with only three cases. Spearman p-values are asymptotic and should be treated cautiously with small samples. Confidence intervals are supplied for mean differences and regression coefficients; Cramer V and standardized t effects are point estimates in v1.

Missingness is listwise across selected variables. Blanks/nulls are missing. Nonfinite, boolean, out-of-range (>1e100 absolute), or nonnumeric values are invalid for numeric roles; literal NA/NaN strings are not silently treated as null. Exclusion counts distinguish missing and invalid rows, with missing taking precedence, and report overlapping per-column missing/invalid counts. No imputation, resampling, random seed or automatic feature selection is used. Category labels retain their original scalar type; independent groups use lexicographic order of these labels. Preview reports counts; the full run checks method feasibility and may reject invalid assumptions.

At least three complete cases are required, each independent group needs two with positive variance, and regression requires more cases than coefficients plus one. Singular designs, constant numeric variables, constant paired differences, perfect OLS fits, nonbinary outcomes, separation/extreme logistic coefficients, nonconvergence and nonfinite results fail explicitly. Low sample size, collinearity, sparse expected counts, normality/variance issues and numerical library warnings are surfaced. Independence, matching, sampling design, logit linearity and causal validity cannot be established automatically. Results make no causal assertions; p-values/CIs are unadjusted for multiple comparisons and logistic diagnostics are in-sample.

Each immutable run stores its ID, UTC timestamp, dataset ID/version/source SHA-256/import options/origin, exact parameters, engine and numerical software versions, exclusion policy and counts, results, diagnostics, caveats and chart data. `output_hash` is SHA-256 of canonical sorted ASCII JSON (compact separators) of the entire manifest excluding that field. History verifies the hash before rendering. Reruns have new IDs/timestamps/hashes but deterministic numerical payloads on the same software versions. SQLite transactions with FULL synchronous persistence prevent partial runs; triggers reject update/delete. Failed runs are not saved and can be retried. Existing dataset and legacy descriptive-statistics records remain intact.

The worker executes only fixed Python implementations using SciPy and statsmodels, never formulas, uploaded code, generated code, AI output or autonomous network calls. Dataset parsing and source integrity checks use the existing registry protections. Numerical workers have a 30-second parent deadline, 25-second CPU limit, one BLAS thread, 1 MiB output/file limit, bounded 16 MiB input, and on Linux a 2 GiB address-space cap. macOS lacks a reliable equivalent address-space limit; input dimensions, runtime, threads and output remain bounded. Existing dataset limits apply (20,000 rows/100,000 cells), with 20 selected variables, 10 regression predictors and at most 100 chi-square cells/20 levels per variable. Scatter and Q-Q charts have at most 200 points, histograms at most 20 bins, Shapiro uses the first 5,000 cases. Persisted manifests are limited to 1 MiB each; immutable history grows with explicit user runs and has no automatic deletion. All storage stays within the registry's private local directory; private dataset/run paths are gitignored. `DEPLOY_MODE` disables Analyse before opening the registry. No external numerical services are used.

Validation: `python -B -m unittest discover -s tests -p 'test_*.py' -v` covers analytical synthetic references, repeatability, invalid inputs, missingness, privacy, immutable history, integrity, timeout and transaction recovery. `PYTHONPATH=.:tests python -B tests/browser_analysis_check.py` runs Chromium against an isolated synthetic workspace, including Dataset Manager handoff, previews, numerical procedures, invalid outcomes, charts, exports, reload/history and navigation. Existing dataset/document/demo browser suites remain required. CI installs SciPy/statsmodels and runs these checks; no personal datasets or paid providers are involved.
