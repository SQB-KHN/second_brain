# SecondSelf — data folder

All knowledge storage lives here.

| Subfolder | Purpose |
|-----------|---------|
| `raw/` | Captured notes, links, and files (JSON + `assets/`) |
| `wiki/` | PARA-organized notes (after classification) |
| `embeddings/` | Vector embeddings for semantic search |
| `graph.json` | Knowledge graph export (after build) |
| `meta.json` | Index of all captures with `file_path` to each JSON |

**Quick open:** `open data/raw` or browse `data/meta.json` for all capture paths
