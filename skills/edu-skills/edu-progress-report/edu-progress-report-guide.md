# Progress Report and Parent Communication

Drafts report comments and parent communication anchored to evidence, written about the work and never the child, each carrying an action and somebody who does it.

---

## Who this is for

Anyone who writes about students to somebody else: school teachers writing report comments, class and form tutors, heads of department and academic coordinators, counsellors preparing for parent meetings, college faculty writing progress summaries, and corporate trainers reporting to a sponsor.

## The problem it solves

Report comments get written for forty students in one evening.

So they come out generic, and a generic comment tells a parent nothing while still costing a teacher four hours. "Has worked well this term and should continue to apply himself" describes nobody, changes nothing, and is indistinguishable from the thirty-nine others.

The comment that would actually change something at home is exactly the same length. It just needs to be anchored to a specific piece of evidence, describe the work rather than the child, and give the parent a job they can actually do. That takes a minute per student if the evidence is in front of you and the structure is decided, and four hours if neither is.

The harder problem is what generic comments turn into under time pressure: character judgements. "Careless", "lacks focus", "does not try" are faster to write than a description of the work, and a child carries them for years.

---

## What you give it

**Required:** the evidence. Marks, observations, submitted work, attendance, whatever the comment has to rest on.

| Context | Why it matters |
|---|---|
| **Who reads it** | A parent, the student, a tutor, an academic head or a training sponsor need different documents, and the second changes the register completely |
| The length limit | Most report systems cap comments, and a truncated comment is worse than a short one |
| **What has already been communicated** | A serious concern should never reach a parent for the first time in a report card |
| Your institution's conventions | What may be said, whether marks are shared, whether comparison is permitted |
| What you want to happen next | A comment with no intended action is a description |

Reports are about named individuals and that is appropriate. Where a whole class is being drafted in one pass, it notes that this can be done with **roll numbers and the names reinstated by you**, which is worth doing. Everything it produces is a draft for you, not something to be sent.

## What you get back

1. Per student: what they can now do, what is not yet secure with its evidence, and **one or two actions with an owner**
2. Draft comments at the required length, in the register for the stated reader
3. **A specificity check**: any comment that would still read true for another student, flagged for rework
4. **An evidence map**: each statement against the mark, work or observation behind it
5. Concerns needing a conversation first, flagged
6. **Unevidenced impressions**, listed separately for you to evidence or drop
7. A cohort summary where asked for, provision first
8. A translation note where another language was produced

## The rule it will not bend

**Describe the work and what to do next. Never the child.**

"Has not yet shown written working on multi-step problems, which is where most of the lost marks are" is a report comment. "Is careless and lacks focus" is a character judgement about a child. It will be read that way, remembered for years, and it gives a parent nothing to act on.

The same holds for potential. Nothing here says a student is bright, weak, gifted, a slow learner or likely to struggle next year. A report records work in a period; it should not become a permanent characterisation of a person who is eleven.

## The swap test

The check that catches almost every generic comment: **swap the name and see whether it still reads true.** If it does, it is not a comment about this student.

Every draft gets run through it, and anything that passes when it should not comes back flagged. Where forty comments are being written in one sitting, this is the check that matters most, because forty comments drift toward a template without anybody deciding to.

## Three parts, and the third is the one that works

| Part | What it says |
|---|---|
| **What they can now do** | Specifically. A capability, not praise |
| **What is not yet secure** | Described as the work, with the evidence |
| **What would move it forward** | One or two actions, **and who does them** |

That third part is where most report comments fail. A parent asked to "encourage more effort" has been given nothing they can do on Tuesday. A parent asked to check that written working appears on maths homework has been given a job.

Balance is not a quota either. A student doing well gets a comment saying specifically what they can do and what the next stretch is, not an invented weakness for symmetry.

## What good output looks like

A strong set of comments could not be shuffled between students. That is the whole test, and it is why the specificity check comes back as a list of things to rework rather than a compliment.

The unevidenced impressions section is usually the useful discomfort. Teachers know things about students that are true and not written down anywhere, and those are exactly the statements a parent challenges in a meeting. It separates them out so you can either find the evidence or drop them, rather than letting them into the report unnoticed.

And if something serious would be arriving in a report card for the first time, it says so and recommends the conversation happens first. That is a professional judgement worth surfacing rather than writing around.

## Using it

Give it the evidence and say who is reading.

Examples that work:

- "38 report comments, 200 characters each, for parents. Marks and my notes attached."
- "Parent meeting tomorrow about a student whose submissions have stopped. Help me structure it."
- "I need to raise a concern with a parent. It has not been mentioned before."
- "Cohort report for the academic head on class 9 maths this term."
- "Rewrite these comments. My head of department says they are too generic."

Saying what has already been communicated is the input that most changes a difficult message.

## Limits worth knowing

- It does not describe a child's character, ability, effort, attitude or potential.
- It does not compare students, rank them, or predict a future grade or outcome.
- It does not attribute a cause to a pattern in the work. What sits behind it is usually outside what the evidence shows, and guessing in writing is where reports do real damage.
- It does not identify or rule out a learning difficulty, and it does not recommend an assessment. It describes what the work shows and names who is qualified to look.
- It does not send anything, and it does not produce a validated translation. Every comment is a draft for you to check, edit and own.

## If something looks wrong

| What you see | Usual cause | Fix |
|---|---|---|
| Comments flagged as generic | They would read true for another student | That is the swap test working. Add the specific evidence. |
| It dropped something you wanted to say | Unevidenced impression | It is in its own section. Find the evidence or leave it out. |
| It refuses to call a student weak | Deliberate, and not negotiable | You get the work described and an action instead, which is what a parent can use. |
| Comments longer than your system allows | Length limit not supplied | Say the character or word cap and it writes to it. |
| It says to talk before reporting | Something serious would be arriving first in a report | A professional judgement, and usually the right one. |
| Cohort report names few students | Provision first, individuals only where a decision needs them | Ask for named detail if a decision requires it. |
